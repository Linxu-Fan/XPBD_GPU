# DiffXPBD

C++17 XPBD cloth demo on the cloth_self_contact branch. F5 loads the pinned skirt with cloth self-contact, runs physics on a worker thread, and displays completed steps in OpenGL. Cloth OBJ frames are written to output. A separate CUDA smoke test launches a kernel and checks its result.

## Eigen3 dependency

The C++ target uses Eigen 3.4.1 through `Eigen3::Eigen`. CMake uses an existing 3.4.1 installation if it finds one. Otherwise it downloads and verifies the upstream release archive during configuration. This first download requires internet access. To use a local installation, pass `-DEigen3_DIR=<directory containing Eigen3Config.cmake>` when configuring.

## Build in Visual Studio 2026

Open `build/visual-studio-2026/DiffXPBD.slnx` in Visual Studio. Select **Debug** or **Release** and **x64**, then choose **Build > Build Solution** (Ctrl+Shift+B). Press F5 to run the `diffxpbd` startup project. To run the GPU check from the IDE, set `cuda_smoke` as the startup project and press Ctrl+F5.

In Solution Explorer, expand **Project Files** to browse the full `src` and `include` trees. CMake keeps compilation sources explicit. Reconfigure the solution to refresh the view after adding files.

The solution is generated by CMake. To recreate it from PowerShell in the project directory, run:

    cmake -S . -B build/visual-studio-2026 -G "Visual Studio 18 2026" -A x64 -T "cuda=13.3"

This configuration uses CMake 4.3.4, the Visual Studio 2026 C++ workload and CUDA 13.3's Visual Studio integration. After building, run the self-contact and CUDA checks with CTest. Use the same configuration you selected in Visual Studio.

    ctest --test-dir build/visual-studio-2026 -C Debug --output-on-failure

## Build with Ninja on Windows

The build script uses CMake 3.24 or newer, Ninja, and the x64 MSVC build tools. The CUDA configuration also requires an NVIDIA GPU, driver, and CUDA Toolkit compatible with the host compiler.

From PowerShell in the project directory, build and test the CUDA configuration:

    .\cmake\build-windows.ps1 -Validate

The executable is at `build/cuda/diffxpbd.exe`. To build and test the CPU configuration:

    .\cmake\build-windows.ps1 -CpuOnly -Validate

The CPU executable is at `build/cpu/diffxpbd.exe`. The two builds use separate directories. Pass `-Fresh` to reset the CMake cache after changing toolchains.

## Project layout

| Module | Public header | Implementation |
| --- | --- | --- |
| Build information | `include/diffxpbd/build_info.hpp` | `src/build_info.cpp` |
| Forward XPBD | `include/diffxpbd/xpbd.hpp` | `src/xpbd.cpp` |
| Constraint derivatives | `include/diffxpbd/linearization.hpp` | `src/linearization.cpp` |
| Backward adjoint pass | `include/diffxpbd/adjoint.hpp` | `src/adjoint.cpp` |
| CUDA constraint sweeps | `include/diffxpbd/cuda/constraint_sweeps.hpp` | `src/cuda/constraint_sweeps.cu` |

`diffxpbd_core` is the static library that owns these modules. Its CMake alias `DiffXPBD::core` provides the public include path and the Eigen dependency to consumers. The `diffxpbd` executable links it and keeps its entry point in `src/main.cpp`. The forward solver includes membrane, bending, and cloth self-contact. Linearization, adjoint, and CUDA constraint kernels remain placeholders.

`DIFFXPBD_ENABLE_CUDA` defaults to `ON` and adds the CUDA module and the separate `tests/cuda_smoke.cu` executable. CMake targets the build machine's GPU by default. Set `CMAKE_CUDA_ARCHITECTURES` to choose another target.
